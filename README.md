# Rapan予約

実家の共有車を、兄弟で取り合いにならないように予約するための小さなWebアプリです。

## 起動

```bash
npm install
npm run dev
```

画面は `http://localhost:5173/` で開けます。同じWi-Fiのスマホから試す場合は、起動ログの `Network` に表示されるURLを開いてください。

## できること

- 月間カレンダーで予約状況を確認
- 使う人、日付範囲、終日または時間指定で予約
- 重複する予約をブロック
- 予約の編集、削除
- 車名と2人分の表示名を変更

予約データは `data/store.json` に保存されます。
